mali.app  —  برنامه اندروید «مالی من» (دخل و خرج شخصی + تنخواه ماموریت)
شناسه برنامه: mali.app    |    حداقل اندروید: ۵.۰ (API 21)    |    بدون نیاز به اینترنت

این پوشه «سورس» برنامه است و باید یک بار به فایل APK تبدیل شود. ساده‌ترین راه (رایگان، بدون نصب چیزی):

روش ۱) ساخت APK با GitHub (حدود ۱۰ دقیقه)
 1. در github.com حساب بسازید و یک Repository جدید (مثلاً mali) بسازید.
 2. گزینه «uploading an existing file» را بزنید و «همه محتوای» این پوشه را بکشید و رها کنید (خود فایل zip را آپلود نکنید؛ ابتدا باز کنید). Commit کنید.
    - اگر پوشه مخفی .github آپلود نشد: Add file ← Create new file ← نام را دقیقاً
      .github/workflows/build.yml  بنویسید و محتوای فایل build.yml همین پوشه را در آن بچسبانید.
 3. تب Actions ← «Build APK» ← Run workflow (یا خودکار بعد از commit شروع می‌شود). ۳ تا ۵ دقیقه صبر کنید.
 4. روی اجرای سبز کلیک کنید ← پایین صفحه Artifacts ← «mali-apk» را دانلود کنید ← zip را باز کنید ← app-release.apk.
 5. فایل APK را به گوشی ببرید و باز کنید. اگر پرسید، «نصب از منابع ناشناس» را برای همان برنامه (مرورگر/فایل‌ها) فعال کنید.

روش ۲) Android Studio روی کامپیوتر
 پوشه را Open کنید ← Build ← Build APK(s). (یا در ترمینال:  ./gradlew assembleRelease )
 خروجی: app/build/outputs/apk/release/app-release.apk

نکته‌ها
 • امضا: یک کلید ثابت (app/mali.jks) همراه پروژه است تا نسخه‌های بعدی روی نسخه قبلی نصب شوند و داده‌ها پاک نشوند.
   رمز این کلید در پروژه نوشته شده؛ برای استفاده شخصی مشکلی ندارد، برای انتشار عمومی (Google Play) کلید جدید و خصوصی بسازید.
 • نام روی صفحه گوشی: app/src/main/res/values/strings.xml  (فعلاً mali.app)
 • داده‌ها فقط روی همان گوشی ذخیره می‌شوند؛ از هر بخش پشتیبان/خروجی اکسل بگیرید.
 • ذخیره فایل (اکسل/پشتیبان) پنجره انتخاب محل ذخیره اندروید را باز می‌کند؛ چاپ، پنجره چاپ/ذخیره PDF اندروید را.
 • روی اندروید ۵ و ۶ بهتر است «Android System WebView» از Google Play به‌روز باشد تا ظاهر برنامه کامل نمایش داده شود.
