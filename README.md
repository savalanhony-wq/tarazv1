# تراز — دخل و خرج شخصی + تسویه تنخواه ماموریت
نسخه ۱۴۰۵۰۹۰۳ (V 14050903) · شناسه برنامه: `mali.app` · حداقل اندروید ۵ (API 21) · بدون نیاز به اینترنت

## ۱) چطور ساخته شد (How it was built)
- برنامه یک **وب‌اپ ساده (HTML + CSS + JavaScript خالص)** است، بدون فریم‌ورک و بدون سرور. فارسی و راست‌به‌چپ.
- همان وب‌اپ دو شکل دارد: **PWA** (پوشه `web/`، نصب از مرورگر) و **اپ اندروید** (پوشه `android/mali-android/`، که همان فایل‌ها را داخل یک WebView می‌گذارد و به APK تبدیل می‌شود).
- دو بخش کاملاً مستقل‌اند و هر کدام داده خودش را نگه می‌دارد:
  - **دخل و خرج** (`personal.html`) — کلید ذخیره `dakhlkharj_v1`
  - **تنخواه ماموریت** (`tankhah.html`) — کلید ذخیره `tankhah_app_v1`
  - تنها پیوند بین آن‌ها: دکمه اختیاری «ثبت بازپرداخت تنخواه» در بخش درآمد.
- داده‌ها فقط در حافظه همین گوشی (`localStorage`) می‌مانند؛ هیچ‌چیز به اینترنت فرستاده نمی‌شود.
- تقویم شمسی با توابع داخلی (`g2j`، چرخه ۳۳ ساله کبیسه) و کلید ماه به شکل `1405-08`.
- APK در **GitHub Actions** ساخته می‌شود (JDK 17، Gradle 8.9، `./gradlew assembleRelease`) و با کلید ثابت امضا می‌شود تا نسخه جدید روی قبلی نصب شود و داده پاک نشود.

## ۴) دستور کار (Instruction)
**ساخت APK:** محتوای `mali-android.zip` را باز کنید ← همه را روی صفحه Upload مخزن GitHub بکشید ← Commit ← تب Actions ← اجرای سبز ← Artifacts ← `mali-apk` ← `app-release.apk` ← نصب روی گوشی.
**نسخه وب:** محتوای `mali-app.zip` را روی هر هاست ثابت بگذارید و از مرورگر «افزودن به صفحه اصلی» بزنید.
**پشتیبان:** در دخل و خرج: تنظیمات ← پشتیبان (JSON). برنامه بعد از ۳۰ روز یادآوری می‌کند. پاک‌کردن اطلاعات برنامه یا حذف آن، داده‌ها را از بین می‌برد.

## ۵) چطور تغییرش بدهم (To change it)
| می‌خواهم… | کجا |
|---|---|
| رنگ کل برنامه | فقط پله‌های `--b50` تا `--b950` در بخش «پایه» `css/theme.css` |
| فاصله، اندازه متن، سایه، گوشه‌ها | توکن‌های `--sp-*`, `--fs-*`, `--sh-*`, `--r-*` همان فایل |
| نام زیر آیکون گوشی | `res/values/strings.xml` ← `app_name` |
| نام در نسخه وب | `manifest.webmanifest` و `<title>` در `index.html` |
| شماره نسخه | `js/version.js` (`APP_VERSION`) + `app/build.gradle` (`versionCode` عدد کامل نسخه، **باید هر بار بزرگ‌تر شود**؛ `versionName`) + نام کش در `sw.js` (`mali-v…`) |
| دسته‌ها و بودجه | داخل برنامه: دخل و خرج ← تنظیمات |
| تعداد ردیف هر برگ چاپ | تنخواه ← تنظیمات و امضاها (۱۰ تا ۷۰؛ جدا برای ریز هزینه و بدون فاکتور) |
| ظاهر چاپ تنخواه | بخش `.pf` در `css/tankhah.css` |
| آیکون برنامه | `res/mipmap-*` (و `icon-*.png` در `web/`) |

بعد از هر تغییر در `web/`، همان فایل‌ها را داخل `app/src/main/assets/www/` هم کپی کنید (به‌جز `sw.js`، `manifest.webmanifest` و آیکون‌های `icon-*.png`)، شماره نسخه را بالا ببرید و دوباره آپلود کنید.

## ۶) دست نزن (Never touch)
- **`app/mali.jks` و رمز آن در `app/build.gradle`**: اگر عوض یا گم شود، نسخه جدید روی قبلی نصب نمی‌شود و باید حذف و دوباره نصب کرد (= از دست رفتن داده). رمز فعلی (`malimali`) برای استفاده شخصی است؛ برای انتشار در فروشگاه کلید خصوصی جدید بسازید.
- **`applicationId 'mali.app'`**: تغییرش یعنی برنامه‌ای کاملاً جدید و داده‌های قبلی در دسترس نیست.
- **کلیدهای ذخیره `dakhlkharj_v1` و `tankhah_app_v1`** و ساختار `S.months / S.rules / S.settings`: تغییر نام یا ساختار، داده‌های ذخیره‌شده کاربر را نامرئی می‌کند.
- **`gradlew`, `gradle/wrapper/`, `.github/workflows/build.yml`**: ساخت ابری به آن‌ها وابسته است.
- **`Reminders.java`، `ReminderReceiver.java`، `BootReceiver.java` و مجوزهای `AndroidManifest.xml`**: اعلان سررسید اقساط به آن‌ها وابسته است.
- **`js/bridge.js`**: بدون آن ذخیره فایل، خروجی اکسل و چاپ داخل اندروید کار نمی‌کند.
- **`versionCode`**: هرگز کاهش نیابد.
- **فایل‌های مولد قدیمی** (`assemble.py`, `split.py`, `raw_*`) را اجرا نکنید؛ سورس اصلی همان پوشه `web/` است و اجرای آن‌ها تغییرات را بازنویسی می‌کند.
